# Code of conduct

## Our pledge

We want boxd to be a project where anyone can report a problem, ask a question or send a change without being
harassed or belittled. We pledge to treat every contributor with respect and to judge a contribution by its content.
The maintainer will remove or edit comments, issues and changes that break this code of conduct.

## Standards

Expected:

- Be kind and patient, especially with people who are new to the project.
- Give specific, useful feedback and accept it the same way.
- Assume good faith, and say so when you disagree.

Not accepted:

- Insults, personal attacks, trolling, and sexualized language or attention.
- Harassment of any kind, in public or in private.
- Publishing someone else's private information without their consent.

## Scope

This code of conduct applies in every space of the project: issues, pull requests, discussions and review comments,
and when someone represents the project in public.

## Reporting

Report a violation privately through GitHub's private reporting on this repository (the "Security" tab, then "Report a
vulnerability"), or contact the maintainer through their GitHub profile. Reports are handled with care and the
reporter's privacy is respected. The maintainer decides what follows, from a private note to a ban from the project.
